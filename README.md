# FunkinSheet Optimizer.. Что это такое?
FunkinSheet Optimizer - это универсальный инструмент оптимизации графики для Friday Night Funkin'. С помощью этого веб-приложения можно: изменить разрешение спрайта, уменьшить размер файла, оптимизировать палитру + ДОП ФИШКИ что подгонят координаты и размеры за вас (пока что лишь для CNE).


**Попробуй прямо сейчас: [--> ПЕРЕЙТИ НА САЙТ <--](https://nickens34.github.io/funkinsheet-optimizer/)**

## Объекты
- All Sprites - работает для оптимизации ЛЮБЫХ спрайтов
- Characters - Вместе с оптимизацией спрайт-листа, так же подгоняет координаты и размер персонажа в файле конфигурации
- Stages - Работает идентично прошлому разделу, подгоняя размер и координаты в файле конфигурации

***⚠️[ВАЖНО]** Разделы CHARACTERS и STAGES работают на данный момент ТОЛЬКО для Codename Engine!*

## Форматы
- Sprite - Спрайт без анимаций, просто картинка
- SpriteSheet - Классический формат для отображения анимаций. Преднозначен для работы с PNG + XML
- SpriteMap - Более новая разновидность упаковки объектов путём размещения их частями и слоями в строго нужных позициях. Преднозначен для работы с PNG + JSON(spritemap) + JSON(Animation)
